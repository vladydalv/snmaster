# Spacenerd Plugins

Master · Tone · Feedback · Era · Stomp

AU (Logic Pro) + VST3, Universal: Apple Silicon + Intel.

## Spacenerd Master — мастеринг
Input → EQ → Compressor → Saturation (Tube / Tape / Soft) → Stereo → True-peak Limiter → Output.
EQ, компресор і сатурація працюють у 4x оверсемплінгу (без «стискання» АЧХ біля 20 кГц і без аліасингу).
- Компресор: soft knee, SC-фільтр, паралельний Mix, **Auto Release** (двоступеневий, менше пампінгу).
- Лімітер: true peak, lookahead 4 мс, двоступеневий реліз (менше спотворень басу).
- Метри: peak, GR, LUFS (BS.1770), максимум true peak на виході.
- **Gain Match**: вирівнює гучність із входом, щоб чесно порівнювати з Bypass. Вимикайте перед експортом.
- **Mix Analyzer**: спектр міксу проти цілі (жанр × десятиліття), вердикти (муть, різкість, пережато, тихо, бас не в моно, фаза), % схожості.
  **LEARN** (10 с найтиповішої частини пісні) → **ASSIST**: виставляє рівень входу, EQ, компресор, лімітер і моно-бас під ціль.

**Release for**: ціль гучності стрімінгу (Spotify / YouTube −14, Apple Music −16, Deezer −15 LUFS, стеля −1 dBTP) — аналізатор оцінює гучність відносно неї, ASSIST виставляє ланцюг і доводить драйв лімітера до цілі за фактичним виміром. **Clip** — м'який кліпер перед лімітером (більше панчу на тій самій гучності).

## Spacenerd Tone — окремі доріжки й шини
Transient → Tube → Tape → Exciter → De-esser, загальний Mix (сухий сигнал вирівняний за затримкою).
- **Tube**: асиметричний тріод (парні гармоніки), Bias, зсув робочої точки від рівня.
- **Tape**: магнітний гістерезис (модель Джайлза–Атертона), швидкість 7.5 / 15 / 30 ips (горб на басу, завал ВЧ), Wow/Flutter.
- **Transient**: Attack / Sustain, не залежить від рівня.
- **Exciter**: гармоніки лише з верхньої смуги.
- **De-esser**: відносний детектор (не треба підганяти поріг під гучність фрази), Listen.
- Лампа і плівка відкалібровані: на -18 dBFS Drive змінює характер, а не гучність.

## Spacenerd Feedback — фідбек гітари з кабінетом
Ставиться на гітарну доріжку **перед** симулятором підсилювача (TONEX, Amp Designer).
Визначає висоту ноти й запускає налаштовану резонансну петлю з ламповим обмеженням: фідбек виростає із самої струни.
- **Trigger**: Auto (нота тягнеться довше Delay), Hold (кнопка, яку можна автоматизувати), Both.
- **Harmonic**: Tone, Octave, Fifth (квінта над октавою), Auto (як у житті: низькі ноти частіше зриваються на октаву/квінту).
- **Distance**: близько — заводиться майже миттєво, далеко — повільно й плавно (до ~6 с). Ближче також скорочує Delay.
- **Morph**: наскільки звук струни перетікає у фідбек. **Tone**, **Drift** (живе «плавання», як рух біля кабінету).
- Заглушили струну — фідбек зупиняється. Нова нота — фідбек переходить на неї.
- **Фідбек у паузі**: HOLD без зіграної ноти — «заводяться» відкриті струни (стрій E / Eb / D / Drop D / C / Drop C / Drop B, струна або Auto).
- Найкраще працює на витягнутих одиночних нотах і квінтах.

## Spacenerd Era — звук епохи одним жестом
Піксельний дисплей: зліва направо — рік (1960…2025), знизу вгору — інтенсивність. Пікселі мерехтять від музики.
Кожна епоха — узагальнення прийомів свого часу: АЧХ, компресія, лампа / плівка / цифровий кліп, стереобаза і типова гучність релізів.
- **Genre**: Neutral, Stoner, Psych, Space Rock, Grunge / Alt — зсуває цілі кожної епохи; класичні роки жанру підсвічені.
- Компресор з авто-порогом (працює і на барабанній шині, і на міксі), авто-гучність під епоху, true-peak лімітер -1 dBTP.
- Інтенсивність 0 = прозоро. **Gain Match** — порівняння з Bypass на однаковій гучності.
- **Split**: бас з одного десятиліття, верх з іншого. Маркери LOW / HIGH на дисплеї: вліво-вправо — десятиліття, вгору-вниз — сила смуги. Пресет вимикає Split.
- **Reference Match**: завантажте WAV/AIFF/MP3 улюбленої платівки — курсор стане на її десятиліття (для обраного жанру).

## Spacenerd Stomp — педаль: драйв/фуз, модуляція, плівкове ехо
Ланцюг: **Octave → Circuit Morph → Modulation → Tape Echo**. Ставити перед амп-симом (TONEX тощо).
- **Circuit Morph** (дисплей: X — схема, Y — гейн): плавний морф між типами схем різних епох — '65 Germanium → '70 British (два «лампові» каскади, напрям Orange) → '73 Triangle (стоунерна стіна) → '81 Op-amp (гранж) → Modern. Гучність вирівняна: морф і гейн не стрибають за рівнем.
- **Battery**: «сіла» батарейка — зсув робочої точки, просідання, тихі хвости нот тріщать і обриваються.
- **Guitar Vol**: ручка гучності гітари перед педаллю. На '65 Germanium прикручування чистить фузз до «скляного» звуку, як на справжньому Fuzz Face.
- **Clean Bass**: низ нижче заданої частоти обходить педаль (для баса: фуз зверху, щільний чистий низ).
- **Octave**: Dry, Sub −2, Sub −1, Up +1, Up +2 (100 % = як вхід, до 200 %), Detune для +1/+2. **Engine** (без змішування, щоб не було «муті»): *Vintage* — емуляція класичного аналогового октавера (аналізатор → D-тригери, однонапівперіодно випрямлений вхід × ±1, полярність міняється лише на нулі сигналу; +1 — випрямляч на виділеній основній), трекер YIN; *Mono HQ* — цифровий зсув висоти гранулами довжиною 2 періоди ноти (чисто на одиночних нотах і басі); *Poly* — банк фільтрів з масштабуванням фази (тримає акорди, на одиночних нотах мутніший); *Spectral* — у дусі POG: +1/+2 спектральним перенесенням піків (чисті акорди вгору, затримка октав ≈ 43 мс), −1/−2 — з банку фільтрів. **Position**: Pre (суб іде в обхід вхідного фільтра драйву) / Post. **Bloom**, **Wobble** (темп — Rate/Sync модуляції). TRACKING — нота, яку чує трекер.
- **Modulation**: Tremolo, Harmonic (низи/верхи в протифазі), Pan (стерео, як у «In Like the Rose» — узагальнено, не копія), Vibrato. **Shape** — від синуса до «рубаного», **Sync** до темпу Logic, **Rise** — модуляція наростає після кожної ноти.
- **Tape Echo**: Time / Sync, Repeats (до самозбудження), Tone, **Wear** (детонація й насичення плівки). Хвости догравають після вимикання.

## Збірка
Автоматично в GitHub Actions при кожному push у `main`.
Готові файли: **Actions** → останній запуск → **Artifacts** → `Spacenerd-Plugins-macOS`.

## Встановлення
1. Розпакуйте `… AU.zip`, перетягніть `.component` у `~/Library/Audio/Plug-Ins/Components`.
2. Один раз для кожного плагіна в Терміналі:
   ```
   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/Spacenerd*.component
   ```
3. Перезапустіть Logic: Audio Units → Spacenerd.

## Нотатки
- Подвійний клік — значення за замовчуванням, **Shift + тягнути** — точно. Вікно масштабується.
- Затримка повідомляється хосту, Logic компенсує її сам.
